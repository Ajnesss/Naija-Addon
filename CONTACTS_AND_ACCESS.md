# Provider integration contacts

The project needs written permission or a documented public API before connecting a provider. This file records public business contact routes only; no message has been sent.

| Provider | Public contact | Ask |
|---|---|---|
| African Movie Channel (Nolly Africa HD / AMCOP) | info@africanmoviechannel.com (official contact page) | Request an authorised FAST channel feed or technical distribution/API partnership for Nuvio; ask whether they can supply an approved HLS/FAST endpoint or an official Nuvio-compatible integration. AMC states that it owns its AMCOP productions and distributes Nolly Africa HD through multiple FAST platforms. |
| Showmine Entertainment | Contact details on its official developer page; integration enquiries invited | Ask for partner API documentation, sandbox credentials, content licensing/territory terms, and whether third-party TV clients are supported. Its public developer page describes an in-house backend/CDN but does not publish a public API. |
| NolliStream | olu@nollistream.com | Is there a partner API/feed or approved title-page linking method for a third-party Nuvio addon? Their terms currently prohibit automated scraping/access. |
| AfroLandTV | Official support/contact route on its website | Do you offer an authorised catalogue feed, partner API or official deep links for a third-party TV addon? |
| AVO TV | Official website contact route | Is a third-party addon integration available under a written agreement? Terms prohibit scraping/reverse engineering. |
| cAfrica | Official website contact route | Is there a documented public catalogue/playback API or partner integration? |
| BlackFameTV | Official website contact route | When will VOD playback be restored, and is a third-party catalogue/deep-link integration permitted? |

Do not send credentials, account cookies, private tokens or user data. Do not ask providers to disable DRM or bypass their access controls.
